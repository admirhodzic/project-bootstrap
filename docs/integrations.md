# Optional integrations

The core package configures no credentials, remote servers, or connectors. Teams may connect issue trackers, design systems, documentation, browsers, or deployment systems when the task benefits and the user authorizes access.

Before enabling an integration, minimize scopes; classify exposed data; review prompt-injection paths in remote content; respect rate limits; and distinguish read, write, and destructive tools. Keep secrets outside repository files. Missing integrations must degrade to a documented manual workflow, never a false completion claim.
